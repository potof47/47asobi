# モンスター・フリック

引っ張って弾く、ひっぱりハンティング系のブラウザゲームです。
ブラウザで `index.html` を開くだけで遊べます（ライブラリ不要・単体ファイル）。
キャラクター・敵・名前・絵はすべてコードで描いたオリジナルです。

## 画面

- **ホーム** … リーダーキャラ、ログインボーナス、図鑑、イベント、音のON/OFF、プレイヤー名（ランキング・協力レイドに表示）、称号
  - **称号** … 20種類（ストーリー50・塔100階・絶級Ⅹ・運極5体・図鑑コンプなど）。初めて取るとジェム30。付けた称号はランキングのリーダー名の前と、助っ人に出る
  - **チュートリアル** … はじめての時だけ、案内妖精ナビがふきだしでヒントを出す（操作・友情コンボ・弱点・SS・ギミック・ガードなど）
  - **ストーリーの会話** … 各章の最初と章ボスを倒した後に、ナビ・リーダー・ボス・混沌の王（第2部は虚無の女王）の会話（1回だけ）
  - **シーズンパス** … ホームの「シーズン」。30日ごとのシーズンで、遊ぶとポイント（クエストクリア+10・Sランク+5・ゲリラ/協力/絶級/超進化+20・
    ログボ+30・デイリー全達成+50・レイド/ボスラッシュ+15）。150ポイントごとに1段階、全30段階の報酬（ジェム・コイン・結晶・紋章・着せ替え券）。無料
  - **チーム** … ホームの「チーム」。10人までのチームを作る・入る・抜ける。今週の協力レイドのダメージ（1000で1pt）とスコアアタックのベストの合計でチームランキング。
    チームの仲間は助っ人の一覧で上に出る（オンライン設定とSQLが必要）
  - **協力プレイ** … ホームの「協力プレイ」。2〜4人がリアルタイムで同じステージ。ホストが部屋を作ってルームコードを教え、
    友だちがコードを入れて参加（入力はゲーム内の入力画面。`window.prompt` は使わない）。人数に合わせて自分の編成の先頭から1〜4体が出撃し、自分のキャラの番だけ撃てる（抜けた人のキャラはホストが動かす）
    - ホストはタブで「協力（初級〜超級）・ストーリー・スペシャル・絶級／神域」から、自分が行けるところまでのクエストを選べる（‹ › で1つ、« » で10個とばし）。
      試練・タイプ専用など編成に条件があるクエストは選べない
    - 参加した人がまだ自分では行けないクエストは、報酬はもらえるがクリア済みにはならない（ストーリーを飛ばせない）。ストーリーの会話・ランキング記録はひとりで遊んだ時だけ
  - **お知らせ** … 管理サイトで書いたお知らせに加えて、アップデート内容が自動で届く（`index.html` の `GAME_NEWS`。
    ゲームを更新するときはここに1件足す）。多い時は「古い ▶」でページ送り
  - **ログインボーナス** … 7日でひと回りのカレンダー（ジェム30 → コイン5000 → ジェム50 → 結晶×3（全属性）→ ジェム80 → コイン15000 → ジェム200）。
    毎日のボーナス（ジェム50・コイン1000、管理サイトで変更可）も一緒にもらえる。その日はじめてホームを開くと自動で表示
  - **図鑑** … 全キャラの一覧（持っていないキャラは「？」。タップで手に入れ方がわかる）。10体集めるごとにジェム100、コンプリートでジェム1000
  - **BGM・効果音** … ホーム・バトル・ボス戦・高難易度のボス戦（絶級・超進化・深淵・神域・レイドなど）で曲が変わる。すべてオリジナルで、
    音声ファイルは使わずその場で合成（和音・アルペジオ・ベース・ドラム）。ホームの「♪ 音」で切り替え。スマホは画面をタップしてから鳴る（マナーモードの時は鳴らない）
- **クエスト** … 全6クエスト。クリアすると次が解放されます
- **ガチャ** … 1回50ジェム / 10連450ジェム（★4以上1体確定）。提供割合 ★6:1% ★5:6% ★4:30% ★3:63%
- **BOX** … 全56体の図鑑（属性タブ・ページ送りあり）。タップで強化・進化
- **キャラの種類** … モンスター・人型（剣士・魔法使い・忍者・騎士など）・獣・鳥・竜・魚
- **ガチャ**（★3〜★5は共通、★6枠のキャラだけが違う）
  - **限定ガチャは3日ごとに入れ替わり**。2026/10/9〜10/11 はスターダスト（ikesaki・ジン 各1%）と灼熱（パニパニ 1%）。
    そのあとはスターダスト → 灼熱 → 超拍手祭 の順に3日ずつ自動で回る（管理サイトで予定したガチャがあればそちらが優先）。
    新しいガチャは `LIMITED_GACHAS` に足すと自動でこのサイクルに入る。ガチャ画面に終了までの残り時間を表示。
  - **超拍手祭** … 2026/10/18〜10/20 が初開催。★6枠は限定キャラ全員（ikesaki・ジン・パニパニ・拍手する猫 各1%）。
    拍手する猫はこのガチャだけで出る
- **★6限定キャラ「拍手する猫」**（闇属性・反射・能力1.55倍で限定キャラ最強）
  - 専用友情コンボ「拍手」… 猫に触れた味方の攻撃力を3ターン1.3倍＋HP回復
  - 専用SS「握手」（8ターン）… 触れた敵の場所で爆発（半径70・攻撃力の6倍）＋敵に触れるたびに加速してまた動き出す
    （今のスピードの1.25倍か撃った時のスピードの速いほう。1回のSSで15回まで）
  - **常設ガチャ** … いつでも引ける。★6枠は恒常★6（紅竜ヴァルカ・蒼姫ミズハ・樹王ドルン・聖騎士アルテ・魔竜ゼノス）合計1%
- **恒常キャラ**（限定以外）は能力1.2倍。恒常★6は各属性に1体（能力1.15倍）。ギミック対策が得意な恒常キャラ10体（ヒエン・レオバーン・スイレン・マンタロス・コノハ・ミドリワシ・キララ・テンマ・ヨイヤミ・ネビュラ）、降臨キャラ3体、キャラ集めのキャラ20体、恒常キャラ追加10体（ホムラマル・ヒバチ・ミナギ・カッパロ・コダマ・ササメ・ヒカリヒメ・ペガス・カゲロウ・ドクロン）を合わせて全127体
- **★6限定キャラ「パニパニ」**（火属性・貫通・能力1.35倍）
  - 専用友情コンボ「加速爆発」… フィールドの約1/4（半径120）の大爆発＋味方全員のSSを1ターン短縮
  - 専用SS「全力応援」（9ターン）… このショットで触れた味方の攻撃力と友情コンボの威力を3ターン2.5倍
- **★6限定キャラ「ジン」**（木属性・反射・能力1.45倍）
  - 専用友情コンボ「気功波」… 敵を追尾するレーザー10本
  - 専用SS「覇王天翔波」（8ターン）… 狙った方向に特大レーザーで大ダメージ（攻撃力の50倍）。
    撃ったターンから5ターン、ジンの攻撃力・HP・スピードが2.5倍になる
- **★6限定キャラ「ikesaki」** … スターダストガチャ(1%)で出るほか、「極・混沌の玉座」の初回クリアで必ずもらえます
  - 能力は通常の★6の1.35倍、スピードも速い
  - 専用友情コンボ「スマイルスター」… 追尾する虹色の星12発（1発 攻撃力0.8倍）＋HP回復
  - 専用SS「フルスマイル・バースト」（8ターン）… 敵全体に攻撃力30倍のダメージ＋敵の攻撃を1ターン遅らせる＋HP30%回復。
    撃ったターンから5ターン、ikesakiの攻撃力・HP・スピードが2.5倍になる
- **編成** … バトルに出す4体を選ぶ（先頭がリーダー）
- **出撃前の編成** … クエストを選ぶと編成画面になり、ギミックに効く能力を持つキャラに水色の帯が付く。上の枠をタップで外す、下の一覧をタップで入れる
  - **おすすめキャラ** … そのクエストの敵の属性に有利か・ギミック対策の能力・強さから4体を選び、金色の枠で一覧の先頭に出す。有利な属性も表示。
    右上の「おすすめ編成」で一発でその4体に編成できる
  - **助っ人** … 5枠目をタップで、ほかのプレイヤーのリーダー（オンライン）かゲストを1体借りて5体で出撃。自分のリーダーも自動で助っ人に登録される
    - **助っ人のお礼** … 自分のリーダーが助っ人として使われてクリアされると、次にホームを開いた時に1回につきコイン1000・ジェム1（1回で最大コイン10万・ジェム30）
    - **フレンド** … 助っ人の一覧の ♡ で登録（30人まで）。フレンドは一覧の上に出る

## クエスト

- **ストーリー** … 全40章・400ステージ（第1部 混沌の王編 20章、第2部 虚無の女王編 20章）。5ステージ目に中ボス、10ステージ目に章ボス。先に進むほど敵が強くなります（ステージは自動生成で、毎回同じ配置）。
- **スペシャル** … 高難度の9クエスト（ランキング対象）。7つ目からは「極・混沌の玉座」より難しい超絶・極限クエスト。
  - 超絶・星喰いの深淵（★7）/ 超絶・終焉の炎神殿（★8）/ 極限・神々の黄昏（★9）
  - **ガード**（六角形のバリア）… 弱点に当てないとダメージが1/4になる。SSや友情コンボも1/4
  - **再生**（緑の＋マーク）… 毎ターンHPが回復する。早く倒さないと削りきれない
  - ボスはガードと再生の両方を持ち、弱点が毎ターン移動します
- **神域** … 「絶級」タブの中の「神域」。限界まで育てたキャラ（★7・Lv120・運極・試練Ⅲ・紋章）でも、うまく戦わないと勝てない5ステージ。
  絶級Ⅴクリアで解放。4WAVE・ガード/再生・ギミック3つ・**20ターン以内にクリアしないと失敗**。初回ジェム1500〜3500
  - **神域Ⅴのごほうび「戦姫アステリア」**（★6・光・貫通・戦乙女、ガチャに出ない。専用に描いた見た目: 鋭い目・刃のような光の翼・翼のかぶと・深紅のマント・構えた大槍・背中の魔法陣）… 神域Ⅴをクリアするたびに必ず1〜2体ドロップ（運極の仲間がいれば+1）。周回で運極にできる。
    試練・超進化（★7）にも対応。能力は限定キャラと同じくらい（AW・AGB）
    - 友情コンボ「絆レーザー」… 触れてきた味方との間にレーザーを張る。その味方（大号令の時は自分）が止まるまで出し続け、味方が動くとレーザーも動き、線上の敵に何度もヒット（1回 攻撃力2.4倍。8フレームごと）。
      アステリアに触れた味方がそのあとほかの味方に触れると、その味方との間にも同じ威力のレーザーが張られる（`chainTether`。先にほかの味方に触れた分はつながらない）
    - SS「大号令」（11ターン）… 味方全員が一緒に飛び出して（それぞれ一番近い敵へ）体当たり＋友情コンボを2回ずつ発動（威力1.5倍）
- **絶級** … クエストの「絶級」タブ。いちばん難しい10ステージ（★10〜★19）。スペシャル「極限・神々の黄昏」をクリアすると解放、1つずつ順番に挑戦。極限より強い。
  4WAVE（中ボス・大ボス）、全部の敵がガード・再生持ち、ギミック2〜3つ。初回ジェム300〜1200、コイン・結晶も大量
- **反射/貫通** … 反射専用・貫通専用ステージ 各10（そのタイプのキャラだけで挑戦）。反射専用は壁ぎわの敵と岩で跳ね返りやすく、
  貫通専用は敵が縦に並ぶ。6ステージ目からガード・再生、3ステージ目からギミック。初回ジェム30〜210
- **塔** … 「無限の塔」「深淵の塔」「ボスラッシュ」をタブの中で切り替え
  - **ボスラッシュ** … ボスだけが最大30体次々に出る。HPは引き継ぎで、倒すたびに20%回復。倒した数で毎週ランキング（オンラインなら全国）。倒した数×3000コイン、自己ベスト更新で1体ジェム10
- **無限の塔** … 終わりのない塔。新しい階をクリアするたびにジェム、10階ごとにボス＆ボーナス。
- **深淵の塔** … 無限の塔を30階までクリアすると挑戦できる、さらに難しい終わりのない塔。
  1階から無限の塔30階以上の強さで、ガード・再生持ちの敵が出ます。毎階2WAVE、5階ごとにガード＋再生のボス。
  報酬も多く、1階からジェム20、10階ごとにボーナスジェム+100。
- **超進化（★7）** … 試練Ⅲをクリアした★6だけが「試練」タブから挑める、とても難しいステージ（4WAVE・ガード/再生・対策しにくいギミック3つ）。
  クリアで★7になり、名前が「超・〇〇」、能力アップ・対策能力+1・SS-1ターン・Lv上限120・金色の光輪
- **試練** … 生まれつき★6のキャラ（限定4体・恒常★6 5体・戦姫アステリア）ごとの強化クエスト。そのキャラを編成に入れて挑戦。
  試練Ⅰ → Ⅱ → Ⅲ の順に解放され、初めてクリアするたびにそのキャラが永久に強くなる。
  - Ⅰ … 能力×1.15 ／ Ⅱ … 能力×1.3・SS-1ターン ／ Ⅲ … 能力×1.5・SS-2ターン・名前に「真・」
  - Ⅲをクリアすると追加能力 **「真の力」** … 敵のガードを無視（ダメージが減らない）＋ボスへのダメージ1.5倍。
    体当たり・友情コンボ・SS・追尾弾など、そのキャラの攻撃すべてに効く。バトル中は金色の輪が回る。
  - 敵はそのキャラが不利な属性も混ざり、Ⅱ以降はガード・再生持ち。最後のWAVEはボス「〇〇の影」

## イベント（ホームの「イベント」）

- **降臨** … 2日ごとにボスが入れ替わる（嵐鳥ゼフィル → 雷獣ライガ → 氷竜グラキエス）。中級・上級・極の3段階。
  ボスのキャラ（★5、★6に進化できる）がドロップする。上級10%・極30%、**極の初回クリアは確定**。降臨キャラはガチャには出ない
  - 降臨キャラは専用の友情コンボとSSを持つ（限定キャラよりは控えめ）
    - 嵐鳥ゼフィル: 竜巻（まわりの敵に2回）／ SS 嵐の翼（攻撃力3.5倍の突撃＋追尾する風の刃12発）
    - 雷獣ライガ: 雷撃（6回連鎖）／ SS 轟雷招来（敵全体に攻撃力12倍＋攻撃1T遅延）
    - 氷竜グラキエス: 氷槍（追尾6本）／ SS 絶対零度（敵全体に攻撃力10倍＋攻撃1T遅延＋HP15%回復）
- **キャラ集め** … 20ステージのうち5つが開催中で、2日ごとに入れ替わる。クリアするたびにそのキャラ（★4・★5、ガチャに出ない）が **1〜5体** ドロップ。
  キャラは各属性4体（ホノオウサギ・ヒノトリ・カジバ・マグロック・アワギツネ・シャチオー・ミズキ・ユキフクロウ・キノコロ・モリジカ・ハヤテ・ツタリュウ・
  ヒカリウオ・コウテイ・ライチョウ・ホシノコ・ヤミギツネ・ヴァンプ・ヨルオオカミ・メイリュウ）。対策能力は5種類が4体ずつ
- **曜日クエスト** … 月=火・火=水・水=木・木=光・金=闇の結晶がたくさん（初級8〜上級30個）。土日は全属性から選べる
- **ゲリラ** … 毎日12時・19時・21時から1時間だけ出る高報酬クエスト（時間ごとに初回ジェム60・コイン3万・結晶12個）。開催中はホームの「イベント」に表示
- **スコアアタック** … 毎週（月曜はじまり）ステージが変わる。何回でも挑戦できる。
  スコア = クリア100,000 ＋ 早さ（30ターンより少ないほど）＋ 残りHP ＋ ヒット数・弱点・撃破・友情コンボ・1ショットの最大ヒット数。
  15万・30万・50万・80万点でジェム50・100・150・300（毎週もらえる）。この端末の記録 / 全国ランキング（オンライン設定時）
- **協力レイド** … 毎週ボスが変わる巨大ボス。1回8ターン、与えたダメージがボスのHPから引かれる（ボスは1回では倒れない）。
  - オンライン設定あり … **みんなで同じボスのHPを削る**（HP 5億）。バトル中も10秒ごとにほかの人のダメージが反映され、ダメージランキングも出る
  - オンライン設定なし … 「ひとりで討伐」（HP 3000万。自分のダメージだけで減る）
  - 討伐されたら、ダメージを与えた人は討伐報酬（ジェム300・コイン50000）。毎回のバトルでもダメージに応じたコイン・結晶

## ジェムの集め方（遊ぶほど増える）

- **プレイヤーランク** … クリアでEXP。ランクアップごとにジェム10、10ランクごとに+50。上限なし。
- **デイリーミッション** … 毎日リセット。クリア・撃破・SS・ガチャ・強化の5つ＋全達成ボーナス（合計ジェム95/日）。
- **実績** … 敵撃破100体ごと、クリア10回ごと、Sランク5回ごと…など、何段でも繰り返しもらえる。
- ほかに、ストーリー・塔の初回クリア、デイリーボーナス、管理者からのプレゼント。

## 育成

- **レア度** … ★3〜★6。レア度ごとにレベル上限（★3:30 / ★4:50 / ★5:70 / ★6:99）
- **強化** … コインでレベルアップ（ATK・HPが上がる）
- **進化** … レベル上限 + 同じ属性の結晶 + コインで★が1つ上がり、名前と見た目が変わります（★5で翼、★6で冠とオーラ）。SSのターン数も短くなります
- **覚醒** … ガチャで持っているキャラが出ると覚醒+1（最大5、1つにつき能力+4%）
- **ラック・運極** … 覚醒が最大のあとに同じキャラが出ると **ラック** が上がる（★3:+2 / ★4:+3 / ★5:+5 / ★6:+10、最大99）。
  ラック1につき能力+0.3%（99で+29.7%）。ラック99で **運極**（アイコンに金色の「極」、リーダーにするとクリア時のコイン1.2倍）。運極のあとはコインに変換
  - キャラ集めのキャラは1体重ねるごとにラック+1
  - **ラックボーナス** … クリア時、編成のキャラのラックに応じて（運極で30%）コイン3000・結晶×3・ジェム10のどれかがおまけで出る
  - 運極のキャラを編成してキャラ集めに行くと、1体につきドロップ+1（最大+2）。運極を作るごとに実績ジェム50
- **天井** … 限定ガチャ（常設以外）を引いた回数が100回たまると、好きな限定キャラ1体と交換できる（ガチャ画面の下）
- **紋章** … キャラ詳細の「紋章」で1体に1つ付けられる装備。攻撃(+12%)・体力(HP+15%)・加速(スピード+10%)・友情(友情コンボ1.4倍)・SS(ターン-1)・
  属性キラー（その属性の敵に1.3倍）の10種類。コイン3万で作れる。シーズンパスでももらえる
- **着せ替え** … キャラ詳細の「着せ替え」。見た目だけ変わる（属性・強さはそのまま）。ほかの属性の色違い（着せ替え券1枚）、
  ゴールド（運極で無料）、シャドウ（券3枚）。着せ替え券はシーズンパスでもらえる
- 結晶とコインはクエストの報酬で手に入ります。クエストでは★3キャラがドロップすることもあります

## バトルの遊び方

- 画面のどこでもドラッグ（引っ張る）して離すと、手番のキャラが逆方向に飛びます。
- 4体のキャラが1ターンずつ交代で行動します。HPはパーティ共通です。
- **反射タイプ**は敵に当たると跳ね返り（攻撃力1.8倍・HP1.1倍）、**貫通タイプ**は敵をすり抜けて多段ヒットします。
- **友情コンボ**: 飛んでいるキャラが味方に触れると、その味方のコンボが発動します（爆発 / 十字レーザー / ホーミング8 / ヒール / チェインサンダー）。
- **ストライクショット(SS)**: ターン経過で溜まり、溜まったら下のアイコンをタップして発動（突撃 / 大波動 / レイン / レーザー / メテオ）。
- **属性**: 火→木→水→火 は2倍（逆は半減）、光⇄闇 はお互い2倍。
- **弱点**（黄色い照準）に当てると3倍ダメージ。ボスの弱点は毎ターン移動します。
- クリアターン数でランク(S/A/B)が決まり、報酬が増えます。

### 特殊な敵

| 敵 | 見た目 | 特徴 |
|---|---|---|
| 爆弾 | 導火線 | 自分の番に自爆して大ダメージ。先に倒すと爆発してまわりの敵を巻き込む |
| ヒーラー | 緑の十字 | 攻撃のかわりに敵全員のHPを15%回復 |
| 盾持ち | 下側の青い盾 | 下（正面）からの攻撃を80%防ぐ（弱点・真の力は防げない）。横や上から当てる |
| 分裂 | ぷるぷるのスライム | 倒すと小さい2体に分かれる |
| 砲台 | 左右の砲身 | 横一直線のレーザーで強い攻撃 |

ストーリーの序盤より後や塔・イベントで、強いステージほど多く出る（ボスは普通の敵のまま）。初めて出た時にナビが説明する。

## ランキング

下のメニューの「ランク」で、クエストごとのクリアターン数ランキングを見られます。

- 何も設定しなければ「この端末の記録」（自分のクリア記録トップ10）だけが表示されます。
- 全員で競う「全国ランキング」にするには、無料の [Supabase](https://supabase.com/) を使います。

### 全国ランキングの設定（1回だけ）

1. Supabase でアカウントを作り、新しいプロジェクトを作成します。
2. 「SQL Editor」で次のSQLを実行します。

   ```sql
   create table scores (
     id bigint generated always as identity primary key,
     name text not null check (char_length(name) between 1 and 12),
     quest int not null check (quest between 0 and 9),
     turns int not null check (turns between 1 and 999),
     leader text check (char_length(leader) <= 30),
     created_at timestamptz default now()
   );
   alter table scores enable row level security;
   create policy "誰でも見られる" on scores for select using (true);
   create policy "誰でも登録できる" on scores for insert with check (true);
   ```

3. スコアアタックと協力レイドも使うなら、続けて次のSQLも実行します。

   ```sql
   create table event_scores (
     id bigint generated always as identity primary key,
     name text not null check (char_length(name) between 1 and 12),
     week int not null check (week between 0 and 100000),
     score bigint not null check (score between 0 and 100000000),
     leader text check (char_length(leader) <= 30),
     created_at timestamptz default now()
   );
   alter table event_scores enable row level security;
   create policy "誰でも見られる" on event_scores for select using (true);
   create policy "誰でも登録できる" on event_scores for insert with check (true);

   create table raid_hits (
     id bigint generated always as identity primary key,
     raid text not null check (char_length(raid) <= 12),
     name text not null check (char_length(name) between 1 and 12),
     damage bigint not null check (damage between 0 and 10000000000),
     created_at timestamptz default now()
   );
   alter table raid_hits enable row level security;
   create policy "誰でも見られる" on raid_hits for select using (true);
   create policy "誰でも登録できる" on raid_hits for insert with check (true);
   -- ボスの合計ダメージ・参加人数と、ダメージランキング
   create view raid_totals with (security_invoker = true) as
     select raid, sum(damage) as total, count(distinct name) as players from raid_hits group by raid;
   create view raid_top with (security_invoker = true) as
     select raid, name, sum(damage) as dmg from raid_hits group by raid, name;
   ```

4. 「Project Settings → API」にある **Project URL** と **anon public** キーを、管理サイトの
   「ゲーム設定 → オンライン（みんなで遊ぶ機能）」に入れて「公開する」で `config.json` を更新します
   （anon キーは公開して大丈夫な鍵です）。これで全国ランキング・スコアアタックの全国ランキング・協力レイドがオンラインになります。
   協力レイドのボスHPも同じ場所で変えられます。

5. 助っ人をオンラインにするには、続けて次のSQLも実行します（ない間はゲストの助っ人6人だけ）。

   ```sql
   create table helpers (
     id bigint generated always as identity primary key,
     name text not null check (char_length(name) between 1 and 12),
     title text check (char_length(title) <= 20),
     fi int not null check (fi between 0 and 999),
     rar int not null check (rar between 3 and 6),
     lv int not null check (lv between 1 and 99),
     awk int not null check (awk between 0 and 5),
     luck int not null check (luck between 0 and 99),
     trial int not null check (trial between 0 and 3),
     created_at timestamptz default now()
   );
   alter table helpers enable row level security;
   create policy "誰でも見られる" on helpers for select using (true);
   create policy "誰でも登録できる" on helpers for insert with check (true);
   ```

6. 助っ人のお礼と、★7（超進化・Lv120）の助っ人登録のために、続けて次のSQLも実行します。

   ```sql
   create table helper_uses (
     id bigint generated always as identity primary key,
     lender text not null check (char_length(lender) between 1 and 12),
     user_name text check (char_length(user_name) <= 12),
     created_at timestamptz default now()
   );
   alter table helper_uses enable row level security;
   create policy "誰でも見られる" on helper_uses for select using (true);
   create policy "誰でも登録できる" on helper_uses for insert with check (true);

   alter table helpers drop constraint helpers_rar_check;
   alter table helpers add constraint helpers_rar_check check (rar between 3 and 7);
   alter table helpers drop constraint helpers_lv_check;
   alter table helpers add constraint helpers_lv_check check (lv between 1 and 120);
   ```

   ボスラッシュのランキングは、スコアアタックと同じ `event_scores` に `week` を 50000 足して保存しています（表の追加は不要）。

7. チーム機能のために、続けて次のSQLも実行します（協力プレイは Realtime を使うので表はいりません）。

   ```sql
   create table team_members (
     id bigint generated always as identity primary key,
     team text not null check (char_length(team) <= 12),
     name text not null check (char_length(name) between 1 and 12),
     created_at timestamptz default now()
   );
   alter table team_members enable row level security;
   create policy "誰でも見られる" on team_members for select using (true);
   create policy "誰でも登録できる" on team_members for insert with check (true);
   ```

## データ

進行状況はブラウザの localStorage に保存されます（キー `mflick-save-v1`）。
ゲームを更新してもデータは消えません（新しいキャラは必ず `FAM` の最後に追加すること）。

### データ引き継ぎ

ホーム画面の「引き継ぎ」から使えます。機種変更や、iPhoneで「ホーム画面に追加」したアプリ
（Safariとデータが別）にデータを移すときに使います。

1. 前の端末で「コードを発行」→ 表示されたコードをコピーして保存
2. 新しい端末で「コードを入力」→ 貼り付けて「確認する」→「上書きして引き継ぐ」

コードはセーブデータを圧縮した文字列（`MF1Z-...`）で、途中で切れていると読み込めません。
コードを知っている人は同じデータを作れるので、他の人に教えないように注意してください。

## 調整のポイント

`index.html` 内の以下を変更すると調整できます。

- `FAM` … キャラ一覧（名前・属性・初期レア度・タイプ・見た目・友情コンボ・SS・体の形）
- `RBASE` / `MAXLV` … レア度ごとの基礎能力とレベル上限
- `EVO_CR` / `EVO_COIN` / `lvCost` … 進化・強化のコスト
- `GACHA_1` / `GACHA_10` / `RATE5` / `RATE4` … ガチャの価格と確率

## アイテム無制限版（検証・デバッグ用）

`unlimited.html` は、ジェム・コイン・結晶が減らない別バージョンです（URL: `…/47asobi/unlimited.html`）。
ガチャ・強化・進化・バランス調整の確認に使います。

- ジェムとコインは常に 9,999,999、結晶は各属性 9,999 に戻ります。
- セーブは別キー `mflick-save-unlimited-v1` に保存されるので、通常版のデータは変わりません。
- ランキングへのスコア送信・オフライン対応（`sw.js`）・ホーム画面追加は無効です。
- `unlimited.html` は `index.html` から自動生成しています。`index.html` を更新したら、次のコマンドで作り直してください。

```
node tools/make-unlimited.js
```
