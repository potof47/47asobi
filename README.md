# モンスター・フリック

モンスターストライク風の、引っ張って飛ばすパズルRPG的ゲームです。
ブラウザで `index.html` を開くだけで遊べます（ライブラリ不要・単体ファイル）。

## 遊び方

- 画面のどこでもドラッグ（引っ張る）して離すと発射されます。引っ張った逆方向に飛びます。
- パーティの生存メンバーごとに1つずつボールが発射されます。
- ボールが敵に当たるとメンバーの攻撃力分のダメージを与えます。
- 敵の頭上の数字は「次の攻撃までのターン数」。0になると味方1人にダメージを与えます。
- 全ての敵を倒すとステージクリア。パーティ全員が倒れると全滅です。
- ステージクリア時、倒れたメンバーも30%のHPで復活します。

## ファイル

- `index.html` … ゲーム本体（HTML5 Canvas）

## 調整のポイント

`index.html` 内の以下を変更すると調整できます。

- `PARTY_DEF` … 味方の名前・色・攻撃力・最大HP
- `STAGES` … 敵の配置・HP・攻撃力・攻撃間隔、ピン（障害物）の配置
- `FRICTION` … ボールの減速の強さ（小さいほどすぐ止まる）
