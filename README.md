# モンスター・フリック

引っ張って弾く、ひっぱりハンティング系のブラウザゲームです。
ブラウザで `index.html` を開くだけで遊べます（ライブラリ不要・単体ファイル）。
キャラクター・敵・名前・絵はすべてコードで描いたオリジナルです。

## 画面

- **ホーム** … リーダーキャラ、デイリーボーナス（1日1回 ジェム50・コイン1000）
- **クエスト** … 全6クエスト。クリアすると次が解放されます
- **ガチャ** … 1回50ジェム / 10連450ジェム（★4以上1体確定）。提供割合 ★6:1% ★5:6% ★4:30% ★3:63%
- **BOX** … 全56体の図鑑（属性タブ・ページ送りあり）。タップで強化・進化
- **キャラの種類** … モンスター・人型（剣士・魔法使い・忍者・騎士など）・獣・鳥・竜・魚
- **★6限定キャラ「ikesaki」** … ガチャ(1%)で出るほか、「極・混沌の玉座」の初回クリアで必ずもらえます
- **編成** … バトルに出す4体を選ぶ（先頭がリーダー）

## 育成

- **レア度** … ★3〜★6。レア度ごとにレベル上限（★3:30 / ★4:50 / ★5:70 / ★6:99）
- **強化** … コインでレベルアップ（ATK・HPが上がる）
- **進化** … レベル上限 + 同じ属性の結晶 + コインで★が1つ上がり、名前と見た目が変わります（★5で翼、★6で冠とオーラ）。SSのターン数も短くなります
- **覚醒** … ガチャで持っているキャラが出ると覚醒+1（最大5、1つにつき能力+4%）。最大の時はコインに変換
- 結晶とコインはクエストの報酬で手に入ります。クエストでは★3キャラがドロップすることもあります

## バトルの遊び方

- 画面のどこでもドラッグ（引っ張る）して離すと、手番のキャラが逆方向に飛びます。
- 4体のキャラが1ターンずつ交代で行動します。HPはパーティ共通です。
- **反射タイプ**は敵に当たると跳ね返り、**貫通タイプ**は敵をすり抜けて多段ヒットします。
- **友情コンボ**: 飛んでいるキャラが味方に触れると、その味方のコンボが発動します（爆発 / 十字レーザー / ホーミング8 / ヒール / チェインサンダー）。
- **ストライクショット(SS)**: ターン経過で溜まり、溜まったら下のアイコンをタップして発動（突撃 / 大波動 / レイン / レーザー / メテオ）。
- **属性**: 火→木→水→火 は2倍（逆は半減）、光⇄闇 はお互い2倍。
- **弱点**（黄色い照準）に当てると3倍ダメージ。ボスの弱点は毎ターン移動します。
- クリアターン数でランク(S/A/B)が決まり、報酬が増えます。

## データ

進行状況はブラウザの localStorage に保存されます（キー `mflick-save-v1`）。

## 調整のポイント

`index.html` 内の以下を変更すると調整できます。

- `FAM` … キャラ一覧（名前・属性・初期レア度・タイプ・見た目・友情コンボ・SS・体の形）
- `RBASE` / `MAXLV` … レア度ごとの基礎能力とレベル上限
- `EVO_CR` / `EVO_COIN` / `lvCost` … 進化・強化のコスト
- `GACHA_1` / `GACHA_10` / `RATE5` / `RATE4` … ガチャの価格と確率
- `QUESTS` / `LAYOUTS` … クエストの敵配置・倍率・報酬
