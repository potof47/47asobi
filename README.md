# モンスター・フリック

引っ張って弾く、ひっぱりハンティング系のブラウザゲームです。
ブラウザで `index.html` を開くだけで遊べます（ライブラリ不要・単体ファイル）。
キャラクター・敵・名前はすべてオリジナルです。

## 遊び方

- 画面のどこでもドラッグ（引っ張る）して離すと、手番のキャラが逆方向に飛びます。
- 4体のキャラが1ターンずつ交代で行動します。HPはパーティ共通です。
- フィールドは四方が壁。止まった場所に次のターンもキャラが残ります。
- **反射タイプ**は敵に当たると跳ね返り、**貫通タイプ**は敵をすり抜けて多段ヒットします。
- **友情コンボ**: 飛んでいるキャラが味方に触れると、その味方のコンボが発動します。
  - ブレイズ: 爆発 / マリン: 十字レーザー / ソーン: ホーミング8 / ルクス: ヒール
- **ストライクショット(SS)**: ターン経過で溜まり、溜まったら下のアイコンをタップして発動。
- **属性**: 火→木→水→火 は2倍（逆は半減）、光⇄闇 はお互い2倍。
- **弱点**（黄色い照準）に当てると3倍ダメージ。ボスの弱点は毎ターン移動します。
- 敵の左上の数字は攻撃までのターン数。ボスは全体攻撃をしてきます。
- フィールドに出るハートに触れるとHP回復。
- 全WAVEを突破するとクエストクリア。クリアターン数でランク(S/A/B)が決まり、ベスト記録が保存されます。

## ファイル

- `index.html` … ゲーム本体（HTML5 Canvas）

## 調整のポイント

`index.html` 内の以下を変更すると調整できます。

- `CHARS` … キャラの属性・タイプ・攻撃力・HP・スピード・友情コンボ・SS
- `QUESTS` … クエストごとのWAVE、敵の配置・HP・攻撃力・攻撃間隔・弱点、岩の配置
- `FRICTION` … 減速の強さ（小さいほどすぐ止まる）
